#  面向英语初学者的 AI 课程

目标是建立英语交流的语言习惯，而非词汇量与语法教学。目标是工作与生活中能与人沟通交流，听得懂，表达得清楚，不需要流利，不需要像美国人，只要能沟通即可。

## 教学原则
- 练中学。注重实战而非教学，教学以练后复盘的形式进行。
- 循序渐进。在每次训练后给出适量的反馈，反馈内容要小于用户的认知负荷，比如一次对话如果 AI 发现 30 个错误，也只指出满足用户认知负载的几个错误，错误按照普遍程度排序，按照用户认知负荷截断。
- 明确反馈。在每次对话中都要有及时复盘，鼓励与纠错并行，每次对话都要让用户进步一点点，但不要多，保持小碎步。
- 动态配速。要实时监控与识别用户的认知负荷，当用户认知负荷高的时候放慢脚步，当用户认知负荷低的时候加快脚步，保持一个用户认知负荷 60%-80% 的 sweet zone。
- 目标明确。只纠正影响交流的问题。不要求纯正语法，不要求地道表达，只要用户能听懂，能敢说，说的内容对方能理解就可以。

##  教学与纠正优先级

| 优先级 | 目标 | AI 是否主动纠正 |
| --- | --- | --- |
| P0 | 对方能听懂我，我能听懂对方 | 必须处理 |
| P1 | 礼貌、工作场景常用表达 | 应该处理 |
| P2 | 表达效率、减少沟通摩擦 | 适度处理 |
| P3 | 语法规范、地道、母语者习惯 | 默认不纠正 |

##  训练阶段

| 阶段 | 目标 | 主要训练 |
| --- | --- | --- |
| ① 生存 | 能开口，不害怕 | 高频工作表达 |
| ② 表达 | 能把事情说清楚 | 复述、解释、回答 |
| ③ 互动 | 能和别人来回交流 | 追问、澄清、反驳 |
| ④ 工作 | 能模拟真实工作 | 面试 + 会议 + 日常工作 |
