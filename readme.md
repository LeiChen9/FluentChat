#  面向英语初学者的 AI 课程

目标是建立英语交流的语言习惯，而非词汇量与语法教学。目标是工作与生活中能与人沟通交流，听得懂，表达得清楚，不需要流利，不需要像美国人，只要能沟通即可。

## 教学原则
- 练中学。注重实战而非教学，教学以练后复盘的形式进行。
- 循序渐进。在每次训练后给出适量的反馈，反馈内容要小于用户的认知负荷，比如一次对话如果 AI 发现 30 个错误，也只指出满足用户认知负载的几个错误，错误按照普遍程度排序，按照用户认知负荷截断。
- 明确反馈。在每次对话中都要有及时复盘，鼓励与纠错并行，每次对话都要让用户进步一点点，但不要多，保持小碎步。
- 动态配速。要实时监控与识别用户的认知负荷，当用户认知负荷高的时候放慢脚步，当用户认知负荷低的时候加快脚步，保持一个用户认知负荷 60%-80% 的 sweet zone。
- 目标明确。只纠正影响交流的问题。不要求纯正语法，不要求地道表达，只要用户能听懂，能敢说，说的内容对方能理解就可以。

##  教学与纠正优先级

| 优先级 | 目标 | AI 是否主动纠正 |
| --- | --- | --- |
| P0 | 对方能听懂我，我能听懂对方 | 必须处理 |
| P1 | 礼貌、工作场景常用表达 | 应该处理 |
| P2 | 表达效率、减少沟通摩擦 | 适度处理 |
| P3 | 语法规范、地道、母语者习惯 | 默认不纠正 |

##  训练阶段

| 阶段 | 目标 | 主要训练 |
| --- | --- | --- |
| ① 生存 | 能开口，不害怕 | 日常口语表达 |
| ② 表达 | 能把事情说清楚 | 工作里的复述、解释、回答 |
| ③ 互动 | 能和别人来回交流 | 追问、澄清、反驳 |
| ④ 工作 | 能模拟真实工作 | 面试 + 会议 + 日常工作 |

## Training Units

### Survival
目标：用户能够：
* 打招呼
* 介绍自己
* 聊自己的生活
* 回答简单问题
* 对别人的话做简单回应
* 主动问一个简单问题
* 在听不懂时请求重复
* 在不会表达时换一种简单说法

#### Units

| Unit | 主题 | 核心交流 |
| --- | --- | --- |
| 01 | Meet Me | 认识一个新朋友 |
| 02 | My Day | 聊今天做了什么 |
| 03 | Food & Coffee | 聊喜欢吃什么、喝什么 |
| 04 | Weekend | 聊周末计划 |
| 05 | My Home | 聊住在哪里、家里有什么 |
| 06 | Free Time | 聊兴趣、电影、音乐、游戏等 |

### Expression
目标：用户能够：
* 说完整句：一轮 1-2 句，不只一词
* 按时间或步骤搭骨架：First / Then / Because
* 流利优先于准确，卡住时换简单说法继续
* 语法仍靠后（P3），只在影响理解时修（P0）
* 聊工作：讲经历、说清做法（带专业细节）、描述工具、说原因、讲不足与提升

#### Units

| Unit | 主题 | 核心交流 |
| --- | --- | --- |
| 07 | At Work | 聊工作日常 |
| 08 | Recent Experience | 聊最近的一段工作经历 |
| 09 | How It's Done | 解释具体工作做法（带专业细节） |
| 10 | Describe It | 描述工位 / 常用工具 |
| 11 | The Reason | 说清工作决定的原因 |
| 12 | What to Improve | 聊哪里不足、怎么提升 |

## Prompt 目录

`prompts/` 按 chapter 分目录：`base.md` 是 Ch1 通用规则，`base-ch2.md` 是 Ch2 表达篇通用规则（流利优先、A2-B1、鼓励完整句），`ch1-survival/`、`ch2-expression/` 各放本阶段的单元 prompt。`worker.py` 按单元号选对应 base，`tools/gen_prompts.py` 递归收集全部 md 并注入 `worker.py`。
