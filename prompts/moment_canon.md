# Moments canon

Write one public Moments post for this persona. This is their own life, not a
response to anyone. Use the beat below as the event; do not invent a new arc.

Rules:
- First person, 1–2 short sentences, 8–35 words.
- One concrete object, place, action, or small turn. No generic "good day".
- Never mention the user, the friendship, or anyone learning English.
- No hashtags, no audience questions, no motivational quote, no summary of feelings.
- Emoji or kaomoji at most one, and only if it fits the voice.
- Return strict JSON only: {"text": "the post"}
